# Оно тебе надо

Страница аукциона по макету Яндекс Практикума.

Для просмотра откройте `index.html` в браузере. Сборка не нужна.

HTML, CSS, Grid и Flexbox. Изображения и шрифты находятся в папках `images` и `fonts`.

Материалы: заготовка `ono-tebe-nado-ad` и [макет в Figma](https://www.figma.com/design/PqHJvUBvwCsv8UmOUPWBXJ/).
